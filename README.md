# VM Guard

VM Guard — контейнеризированная система контроля доступа к операциям с образами виртуальных машин.

Проект реализован на Python с использованием Django и предназначен для учебной демонстрации механизмов аутентификации, авторизации, разграничения операций над образами виртуальных машин, применения ограничений для отдельных образов, а также контейнеризации и оркестровки программного средства средствами Docker и Kubernetes.

## Назначение проекта

Приложение выполняет проверку возможности выполнения пользователем определённой операции над выбранным образом виртуальной машины. При принятии решения система учитывает логин пользователя, пароль, роль, выбранный образ, тип операции и условие доступа по защищённому соединению.

Результатом работы является вывод решения о разрешении или запрете операции.

## Используемые технологии

- Python 3
- Django
- PostgreSQL
- Nginx
- Adminer
- Docker
- Docker Compose
- Kubernetes
- Docker Desktop

## Архитектура системы

В составе системы используются четыре контейнера:

1. `nginx` — внешний веб-сервер и точка входа в приложение;
2. `django-app` — контейнер с основной прикладной логикой;
3. `postgres` — контейнер базы данных PostgreSQL;
4. `adminer` — контейнер веб-интерфейса администрирования базы данных.

## Основные функции

Система обеспечивает:
- проверку логина и пароля пользователя;
- определение роли пользователя;
- проверку допустимости операции для выбранной роли;
- применение ограничений для отдельных образов виртуальных машин;
- контроль доступа при использовании HTTP/HTTPS;
- выдачу результата проверки через веб-интерфейс;
- работу в контейнерной среде Docker и Kubernetes.

## Структура проекта

- `manage.py` — управляющий файл Django;
- `django_project/` — настройки проекта;
- `tasks/` — логика приложения и HTML-шаблоны;
- `requirements.txt` — зависимости Python;
- `Dockerfile` — файл сборки контейнера приложения;
- `docker-compose.yml` — конфигурация многоконтейнерного развертывания;
- `config.yaml` — Kubernetes-манифест;
- `nginx/default.conf` — конфигурация nginx;
- `README.md` — описание проекта.

## Результат работы

Проект был адаптирован для:
- локального многоконтейнерного запуска через Docker Compose;
- развертывания в Kubernetes-кластере;
- подключения к PostgreSQL;
- публикации Docker-образа в Docker Hub;
- тестирования контейнера безопасности на подготовленном наборе данных.
